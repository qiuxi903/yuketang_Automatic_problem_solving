# answer-lib 答案库模块

> 平台的答案数据源。按批次存放历次作答的试卷答案，供 matcher 匹配、collector 采集回写。
> 配套答题铁律：`../docs/雨课堂答题AI提示词.md`

## 使用方式（AI 与真人通用）

1. 先按批次进目录：`10-01/`、`09-24/`
2. 再按题干定位：在该目录对应的试卷文件里，用题干的连续文字片段搜索（如「区块链的核心特征」）
3. 取答案：每条答案都写在 `- 答案：` 之后，直接读这一行
4. 按文本选选项：在雨课堂页面上找到文字与答案一致的选项再点。不要按 A/B/C/D 字母或选项序号作答，雨课堂的选项顺序会被随机打乱，按序号会整片错位

## 批次目录

- `10-01/`：批次 2026-10-01，30 套 1626 题，得分 100%
- `09-24/`：批次 2026-09-24，6 套 418 题，得分 100%
- 合计：36 套 2044 题，得分率 100%

各批次明细见对应目录下的 `README.md`。

## 每条记录的格式

```markdown
**12.** 以下哪个IP地址不能在公网使用？（）

- 答案：172.16.0.1
```

- `**12.**`：题号
- 紧随其后的文字：题干原文，用于检索与人工核对
- `- 答案：`：正确选项的文字内容

## 平台接入

- `manifest.json`：机器可读清单，含批次、试卷名、题量、得分、文件路径
- 导入：backend 启动或手动触发时读取 `manifest.json` 与各 md，写入 MySQL 的 paper 与 question 表
- 匹配：matcher 按题干归一化与相似度定位选项索引，输出 IDX
- 回写：collector 采集到新答案后，按同一格式写入 md，并更新 `manifest.json`

## 文件说明

- `manifest.json`：答案库清单
- `10-01/`、`09-24/`：各批次答案文件
- `10-01.zip`：10-01 批次打包备份
- `10-01批次统计报告.html`：10-01 批次统计报告
