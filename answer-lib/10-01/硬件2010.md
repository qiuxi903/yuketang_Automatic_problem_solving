**1.** Cache是用SRAM组成的一种高速缓冲存储器，下列有CPU访问Cache的叙述正确的是 ( )。

- 答案：Cache中的数据是主存很小一部分内容的映射(副本)

**2.** 下列与存储程序控制核心思想不相符的是 ( )。

- 答案：人在存储程序中处于核心地位

**3.** 40X的DVD光驱，读取速率数据值约为 ( )。

- 答案：54MB/S

**4.** 硬盘的容量大小与 ( ) 无关。

- 答案：盘片厚度

**5.** 如果计算机出现开机不启动的现象，不可能是以下原因造成的 ( )。

- 答案：没有安装应用程序

**6.** 下列关于激光打印机的叙述中，正确的一条是 ( )。

- 答案：激光打印机是激光技术和静电复印技术相结合的产物,是常见的硬复制设备

**7.** 下列不属于显示器技术指标的是 ( )。

- 答案：显存大小

**8.** CMOS用来保存当前系统的硬件配置和用户对某些参数的设定，它是主板上一块特殊的 ( ) 芯片。

- 答案：RAM

**9.** 下列关于I/O接口以及设备的叙述中不正确的是 ( )。

- 答案：外设通过I/O接口可以直接与CPU相连

**10.** CPU执行一条指令的过程中，从存储器读取数据时，正确搜索数据的顺序是 ( )。

- 答案：L1Cache;L2Cache;DRAM和外存

**11.** 主板上标有HDD.LED的地方，表示的是 ( )。

- 答案：硬盘运行指示灯

**12.** 关于高速缓存(cache)与主存的关系，下列描述中错误的是 ( )。

- 答案：程序员可以根据需要调整cache容量的大小

**13.** 在以下设备中，存取速度最快的是 ( )。

- 答案：CPU的寄存器

**14.** 我们通常将图像在CRT屏幕上更新的速度称为 ( )。

- 答案：刷新频率

**15.** 下列各项中，决定显示器清晰程度的主要技术指标是 ( )。

- 答案：分辨率

**16.** 下列因素中，对微型计算机工作稳定性影响最小的是 ( )。

- 答案：噪声

**17.** 在购买微型计算机时，铭牌上标注的"酷睿2"或"酷睿3"(core)指的是 ( )。

- 答案：CPU的型号

**18.** CPU的接口类型很多，现在大多数CPU的接口为 ( ) 接口。

- 答案：触点式

**19.** 关于主板上CMOS钮扣电池的作用，以下说法正确的是 ( )。

**20.** 将PS/2接口的键盘和鼠标连接到ATX结构主板上PS/2接口，其正确接法为 ( )。

**21.** 用来标注显示器显示区域大小的参数称为 ( )。

**22.** 下列有关总线和主板的说法中，叙述错误的是 ( )。

**24.** 显示适配器上存放图形数据的芯片是 ( )。

**27.** 电脑在使用过程中的噪音一般是由于风扇造成的，( ) 的风扇是最有可能发出噪音的。

**28.** 用24位来存储一种颜色的数字视频信号表示的最大颜色数是 ( )。

**29.** 以下说法正确的是 ( )。
