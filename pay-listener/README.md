# pay-listener · 免签监听（电脑端）

监听**微信/支付宝电脑客户端**窗口里的收款消息，回调后端自动核销 VIP 订单——
用户在付费页按「含随机尾数的精确金额」扫码付款，钱进你的个人收款码，订单几秒内自动到账。

零手续费、零支付资质、零备案；不碰手机、不碰系统通知，纯读电脑上已登录的客户端窗口。

## 快速开始

```powershell
cd pay-listener
pip install -r requirements.txt
copy config.example.ini config.ini   # 编辑 backend_url 和 listen_token
python listener.py --selftest        # 金额解析自检（不联网）
python listener.py --probe-uia       # 校准：确认能读到微信会话条目
python listener.py                   # 常驻运行
```

`listen_token` 在管理后台 **VIP 运营 → 支付与活动 → 监听令牌** 复制。

## 策略选择

| 策略 | 原理 | 适合 | 风险 |
|---|---|---|---|
| `uia`（默认起点） | 读微信窗口控件树里的会话预览（零注入） | 微信 3.x 直接可用；4.x 需先 `--probe-uia` 校准 | 无 |
| `ocr`（兜底） | 截微信窗口 → RapidOCR 离线识别 → 提金额 | UIA 读不到条目（如微信 4.x 弱化无障碍树） | 无；首次运行下载 ~15MB 模型 |
| `auto` | uia 连续失败 5 次自动切 ocr | **推荐** | 无 |
| `wcf` | wcferry 注入钩子（仅微信 3.9.x） | 极端情况才考虑 | **有封号风险，默认别开** |

**首次部署校准步骤**：微信登录并保持前台（可遮挡、不可最小化）→ `python listener.py --probe-uia`
→ 输出里能看到「微信支付」会话条目即可直接用 `auto`；读不到条目就 `strategy=ocr`。

## 开机自启（可选）

任务计划程序 → 创建基本任务 → 触发器「登录时」→ 操作：
`python.exe G:\project\做题\做题-vip\pay-listener\listener.py`（起始于 pay-listener 目录）。

## 工作原理与防重复

1. 用户下单 → 付费页展示 `应付 = 价格 − 折扣 + 随机尾数(1~99分)`，10 分钟有效；
2. 用户扫你的个人收款码，手动输入该精确金额；
3. 微信电脑版收到「微信支付 收款X.XX元」消息 → 监听器提取金额 → `POST /api/pay/notify?token=...`；
4. 后端按「金额精确相等 + 10 分钟内创建的待支付订单」自动核销并发权益；撞单（同金额多单）取最早的一单，其余留人工；
5. 监听器重复回调是安全的（订单已 PAID 不会再匹配）；漏单走后台「粘贴收款文本快速核销」或「确认到账」按钮。

## 已知边界（诚实清单）

- UIA 控件树随微信版本变化：换微信版本后先重跑 `--probe-uia`；
- 微信窗口最小化 / 收进托盘时读不到内容（遮挡没关系），`ocr` 同理；
- 两笔**同金额**订单同时待支付时，随机尾数只有 1/99 概率撞上——撞上了第二笔留人工兜底；
- 支付宝电脑客户端的 UIA 结构未实测，`keywords` 里加了「支付宝」作为实验项，主力建议微信。
